# 页面目标

让客户在同一页面实际比较两种作品投票交互，确认两级分类呈现，并验证部分作品同时参与慈善义拍的竞拍流程。

# 页面入口与出口

- 入口：客户确认链接或本地原型入口。
- 出口：提交投票成功反馈；提交竞拍成功反馈；关闭作品预览。

# 页面结构

1. 客户确认工具条：方案切换、演示状态。
2. 一级分类：Chinese Culture / Child Friendly City。
3. 二级分类：All / G2-G3 / G4-G5 / G6-G8 / G9-Adult / P-G1。
4. 作品选择标题行：右侧提供 Bid Only，用于只查看参与慈善义拍的作品，避免受二级分类数量影响。
5. 作品卡片区：作品图、眼睛预览按钮、编号、选择控件、投票按钮及义拍作品的 Bid 按钮。
6. 底部提交按钮。
7. 竞拍表单：人民币竞拍金额、姓名、角色、家长子女信息、手机和邮箱。
8. 大图预览弹窗、Toast 反馈。

# 关键交互

- 切换一级分类后，二级分类自动回到 All，作品列表同步刷新。
- Bid Only 可与当前一级、二级分类组合筛选；关闭后恢复显示该分类下的全部作品。
- 方案 1：点击作品图片选中；点击眼睛仅预览并阻止选中事件。
- 方案 2：不显示眼睛按钮；点击图片放大预览，点击投票按钮选中作品。
- 两种方案都必须点击底部提交按钮才正式提交。
- 仅后台标记为参与义拍的作品显示 Bid；点击 Bid 不改变当前投票选择。
- 竞拍人与金额等必填项校验通过后，竞拍单独提交；家长角色额外必填孩子姓名与年级。
- 提交时按钮进入处理中状态并防止重复点击。

# 关键状态

- 正常态：显示作品列表。
- 未选择：提交时给出提示，不产生提交。
- 提交中：禁用提交按钮。
- 提交成功：Toast 明确显示作品编号。
- 竞拍校验失败：在对应字段下显示错误，不关闭竞拍表单。
- 竞拍提交中：禁用提交按钮，避免重复提交。
- 竞拍提交成功：关闭表单并反馈作品编号与报价金额。
- 加载态：显示骨架屏。
- 空态：显示当前分类暂无作品。
- 错误态：显示加载失败和重试入口。

# 待确认项

- 客户最终选择方案 1 或方案 2。
- 一级、二级分类是否均为单选且发布必填。
- 二级分类的正式名称、顺序及其与一级分类的对应关系。
- 是否允许已提交的用户再次投票或修改投票。
- 参与义拍作品由谁配置，以及 Bid 开放与截止时间。
- 竞拍是否需要起拍价、最低加价幅度、最高报价展示和重复出价规则。
- 联系信息用途提示的最终隐私文案。
