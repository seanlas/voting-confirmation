# 页面目标

让后台管理员在投票截止后集中查看竞拍信息，并直接下载清晰、完整的竞拍清单。

# 页面入口与出口

- 入口：后台活动管理中的慈善义拍竞拍清单。
- 出口：下载当前筛选结果的 CSV 竞拍清单。

# 页面结构

1. 汇总区：竞拍记录数、参与义拍作品数、已提交的最高报价、最后提交时间。
2. 筛选区：关键词、作品编号、角色。
3. 清单表格：作品分类、人民币竞拍金额、竞拍人、角色、孩子姓名与年级、手机、邮箱和提交时间。
4. 下载按钮：导出当前筛选范围内的完整字段。

# 关键交互与状态

- 搜索与筛选实时更新表格，重置可恢复全部记录。
- 下载按钮生成 UTF-8 CSV 文件，保留手机和邮箱等跟进字段。
- 覆盖正常、加载、空结果和加载失败状态。

# 待确认项

- 后台入口所属菜单与有权查看、下载竞拍人个人信息的角色。
- 下载格式最终采用 CSV 还是 XLSX。
- 是否需要展示同一作品的当前最高报价、出价次数或竞拍状态。
- 投票截止与竞拍截止是否使用同一时间。
